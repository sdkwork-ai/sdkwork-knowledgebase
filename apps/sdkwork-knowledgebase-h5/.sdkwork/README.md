# .sdkwork/

Repository/application AI workspace metadata for `apps/sdkwork-knowledgebase-h5`.

## Purpose

Owns H5 application-root local skills, local plugins, and workspace manifests
governed by `../../../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md`.

## Structure

- `skills/`: H5-local agent skills.
- `plugins/`: H5-local agent plugins.
- `local/`, `tmp/`, `cache/`, `secrets/`: local-only state, not version controlled.
