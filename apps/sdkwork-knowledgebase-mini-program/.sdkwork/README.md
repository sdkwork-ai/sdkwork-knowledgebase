# .sdkwork/

Repository/application AI workspace metadata for `apps/sdkwork-knowledgebase-mini-program`.

## Purpose

Owns mini-program application-root local skills, local plugins, and workspace
manifests governed by `../../../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md`.

## Structure

- `skills/`: mini-program-local agent skills.
- `plugins/`: mini-program-local agent plugins.
- `local/`, `tmp/`, `cache/`, `secrets/`: local-only state, not version controlled.
