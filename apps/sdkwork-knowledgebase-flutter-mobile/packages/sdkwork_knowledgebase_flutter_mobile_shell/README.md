# sdkwork_knowledgebase_flutter_mobile_shell

Application shell for the Knowledgebase Flutter mobile root: navigation
registry and auth gate evaluation.

Route guards are shell/runtime responsibilities. Capability packages declare
auth mode and permission hints only.

Authority: `FLUTTER_APP_MOBILE_ARCHITECTURE_SPEC.md` section 3 and
`APP_CLIENT_ARCHITECTURE_ALIGNMENT_SPEC.md` section 7.
